# הדרכה בנשיא

ספריית ההדרכה של שבט הנשיא: כל הפעולות, תיקי הטיול והמאגרים של השבט במקום אחד, עם עורך פעולות, בונה תיקי טיול וסמינרים, וייצוא ל־Word.

## מה יש באתר
- **ספרייה**: 216 פעולות, 10 תיקי טיול, סמינרים, וכ־1,100 רכיבים לשימוש חוזר (משחקים, טקסטים, שאלות לדיון, הפעלות, זמני צופיות). חיפוש בעברית שסולח על טעויות, סינון לפי סוג, נושא וקהל, ומיון לפי שנת הפעילות.
- **עורך פעולות**: לפי מרכיבי "המסע בצופים" (מפקד, זמן משחק, הפעלה, דיון, טקסט, נקודת מבט, זמן עצירה, זמן צופיות, סיכום). גרירה לשינוי סדר, חישוב זמנים ולו״ז אוטומטי, רשימת ציוד, ובדיקת מוכנות.
- **תיקי טיול וסמינרים**: לפי המבנה של תיקי הטיול של השבט, עם נקודת מבט לכל מדריך, שיקופי מצב, לו״ז עם זיהוי חפיפות, ציוד שמחושב לפי מספר המשתתפים, תפריט ותקציב, וצ׳ק ליסט.
- **ייצוא**: Word (מימין לשמאל), טופס "אסמכתא לאישור הפעולה", קובץ להדפסה/PDF, וטקסט לוואטסאפ.

## הרצה מקומית
```
python -m http.server 8000
```
ואז לפתוח את http://localhost:8000.

העבודה האישית נשמרת בדפדפן. כשהאתר פתוח מתוך Claude היא נשמרת גם בחשבון ומסתנכרנת בין מכשירים.

## מבנה
- `index.html`, `core.js`, `views.js`, `editor.js`, `plan.js`, `export.js`, `boot.js`: האתר עצמו, בלי תלויות בנייה.
- `data/library.json`: הספרייה, נבנתה מתיקיית "הדרכה" בדרייב. שמות חניכים הוסרו ממנה.
- `img/`: הסמל של השבט.
- `scripts/`: הסקריפטים שהפכו את קבצי הדרייב לספרייה (`extract.py`, `build_library.py`).
